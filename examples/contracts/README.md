# Contract Examples

These synthetic records demonstrate the difference between an untrusted action proposal and an accepted canonical event.

- [`action-proposal.json`](action-proposal.json) is a request that still requires schema, permission, state, and rule validation.
- [`canonical-event.json`](canonical-event.json) records the accepted result after trusted resolution.

They are fixtures for specification review and future tests. They are not output from an implemented engine.
